# [The Last Canary]

# 📌 Topic
Unreal Engine 5를 활용 한 1인칭 멀티 호러게임 제작

## 🖥️ 기획 배경

> **"죽음을 앞당기는 경고, 카나리아의 마지막 울음."**

《The Last Canary》는 고립된 탐험지에서 펼쳐지는 불신, 생존, 팀워크 중심의 심리적 공포를 다루며,  
**정신 오염, 탈출, 진실에 대한 추리적 요소**를 중점적으로 그린 협동 탐험 게임입니다.

## 🚩 핵심 시스템

| 시스템 | 설명 |
|--------|------|
| 🧠 **보스 추론 시스템** | 수집한 쪽지와 단서를 토대로 보스 정체 유추, 체크리스트로 평가 |
| 🛰️ **드론 조작/수집 시스템** | 위험 지역 정찰 및 자원 회수 가능, 전략적 활용 |
| ⚙️ **맵 기반 기믹 퍼즐** | 저울, 스플라인 카트, 협동 발판, 순서 퍼즐 등 레벨 특화 |
| 💬 **거리 기반 보이스챗** | 거리 제한 대화 + 무전기 활용, 사망자는 사망자끼리만 대화 가능 |
| 🛍️ **상점 & 커스터마이징** | 드론 배송, 외형/장비/치장 아이템 구성 |
| 📈 **결과 평가 시스템** | 생존, 정답률, 자원 수집량 기반 점수 및 랭크 평가 |
